# AI에게 맡기는 프롬프트

이 저장소를 AI 코딩 도구(Claude Code 등)로 연 뒤, 아래 내용을 그대로 붙여넣으세요.

---

이 저장소는 개인 링크 페이지입니다. 내 정보로 채워 주세요.

**규칙**
- 콘텐츠는 `src/content/site.json`만 고칩니다. 컴포넌트와 CSS 구조는 건드리지 마세요.
- 색을 바꿔야 하면 `src/app/globals.css`의 `:root` 변수만 고칩니다.
- 내가 답하지 않은 항목은 **지어내지 말고** 그대로 두거나 나에게 다시 물어보세요.
- 다 고친 뒤 `npm run build`로 확인해 주세요.

**먼저 나에게 물어봐 주세요**
1. 표시할 이름과 직함(예: 국어교사, 연수 강사)
2. 첫 화면에 넣을 한두 문장 — 내가 어떤 사람인지
3. 지금 만들고 있는 것 (포스트잇에 손글씨로 들어갑니다)
4. 나를 설명하는 해시태그 5~6개
5. 연락처 — 메일, 블로그, SNS, 강의 문의 창구
6. **활동을 어떤 갈래로 나눌지** (예: 수업 / 연수·강의 / 글·기록 / 도구·자료)
7. 각 갈래에 넣을 링크 — 이름, 한 줄 설명, 주소
8. 연도별 활동 이력
9. 프로필 사진과 첫 화면 배경으로 쓸 이미지 (없으면 지금 것을 그대로)
10. 파비콘과 카카오톡 공유 이미지의 분위기

**참고**
- `works`의 `category`는 `categories`의 `id`와 반드시 일치해야 합니다.
- `icon`은 `public/icons/`에 있는 파일 이름만 쓸 수 있습니다.
- 새 이미지는 `public/assets/`에 넣고 webp로 줄여 주세요(가로 1440px 이하 권장).
